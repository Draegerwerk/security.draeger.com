### [Update A - BadAlloc vulnerabilities (CVE-2021-22156) in QNX and other real-time systems: Dräger devices not affected](<advisories/2021-10-01-PSA-21-231-01-update-a-badalloc.pdf>)

PSA-21-231-1-A · 2021-10-01

BadAlloc is a group of memory corruption vulnerabilities in several real-time operating systems. They can cause a denial of service or remote code execution. Dräger uses WindRiver VxWorks in some devices. With help from WindRiver, Dräger analysed its devices and found that none uses the affected functions in an exploitable way. Dräger medical devices are not affected.
