### [Dräger CC-Vision Basic and CC-Vision E-Cal security vulnerabilities](<advisories/2021-03-02-PSA-21-061-1-CC-Vision-Product-Security-Advisory.pdf>)

PSA-21-061-1 · 2021-03-02

CC-Vision does not check .gdt device files correctly, and a buffer can overflow. A specially made .gdt file can stop the program or run malicious code on the computer. CC-Vision Basic up to 7.5.2 and CC-Vision E-Cal up to 7.2.4.8 are affected. Users must install Basic 7.5.3 or E-Cal 7.2.5.0 or higher, and must check the source of .gdt files before they open them.
