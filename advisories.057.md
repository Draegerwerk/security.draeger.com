### [REGARD 7000 OPC UA Server Security Vulnerabilities](<advisories/PSA-26-295-1-REGARD-7000-OPC-UA.pdf>)

PSA-26-295-1 · 2026-10-23

Dräger investigates if the REGARD 7000 OPC UA Server is affected by two critical PHP vulnerabilities, CVE-2026-109618 and CVE-2026-109619. The investigation is not complete. The instructions for use state that the OPC UA server is not approved for public networks. Operate the REGARD 7000 only in protected networks.
