### [PrintNightmare Microsoft Windows security advisory](<advisories/PSA-21-207-1_Security_Advisory.pdf>)

PSA-21-207-1 · 2021-07-26

The Windows Print Spooler service does privileged file operations incorrectly. An attacker can use this fault to run any code with SYSTEM rights. Dräger analysed all products that use Windows. These products are not exposed, or you can protect them with the usual operating system patches or with the Microsoft workarounds. Dräger tests patch compatibility each month.
