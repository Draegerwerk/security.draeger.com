### [TLS 1.0 advisory: Infinity Gateway VF7.2 and VF9.0/VF9.0.1 need TLS 1.0](<advisories/PSA-22-4-1-TLS-1-0-Security-Advisory_rev3.pdf>)

PSA-22-004-1 · 2023-04-21

Gateway VF7.2 on Windows Server 2012 R2 and Gateway VF9.0/VF9.0.1 on Windows Server 2016 need TLS 1.0. Their services stop if you disable TLS 1.0. Dräger tells users to keep TLS 1.0 enabled on these servers. Dräger recommends an upgrade to Infinity Gateway VF9.0.1 on Windows Server 2019, which uses TLS 1.2 only.
