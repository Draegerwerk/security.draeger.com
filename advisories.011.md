### [CVE-2019-11687 vulnerability in the DICOM file format: Dräger medical devices are not affected](<advisories/2019-06-19-DICOM-CVE-2019-11687-Security-Advisory.pdf>)

PSA-19-170-1 · 2019-06-19

In April 2019, the security company Cylera published a vulnerability in the DICOM file format. Dräger medical devices do not use DICOM files, for import or for export. Therefore Dräger medical devices are not affected and users need no action.
