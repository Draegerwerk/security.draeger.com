### [Dräger Clinical Assistance Package (CAP1) security vulnerability CVE-2020-13576 in gSOAP](<advisories/2021-06-24-PSA-21-173-1-CAP1-Security-Advisory.pdf>)

PSA-21-173-1 · 2021-06-24

The gSOAP library in CAP1 devices has an integer overflow (CVE-2020-13576). A remote attacker can send a special SOAP HTTP request, make the system stop, or possibly run malicious code. The affected products are Dräger CC300 1.1.1, Dräger IACS VG7.1/VG7.1.1 and Infinity Gateway VF9.0. Dräger rates the risk as negligible and asks for no action.
