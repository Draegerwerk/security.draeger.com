### [Vista 120 CMS security vulnerability CVE-2023-43208 in NextGen Mirth Connect](<advisories/PSA-24-183-2-Product-Security-Advisory-Vista-120CMS.pdf>)

PSA-24-183-2 · 2024-08-16

CVE-2023-43208 lets an attacker run code remotely on NextGen Mirth Connect before version 4.4.1. Mirth Connect is an optional part of Vista 120 CMS, versions 1.6 to 1.64.02. Only installations where Mirth Connect runs are vulnerable. Users must check the CMS version and the Mirth Connect state in the Factory Maintain tab.
