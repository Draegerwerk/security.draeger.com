### [CVE-2020-1350 SIGRed Windows DNS Server vulnerability - Dräger medical devices are not affected](<advisories/PSA-20-216-01-SIGRed-Security-Advisory.pdf>)

PSA-20-216-1 · 2020-08-04

SIGRed is a vulnerability in the Windows DNS Server. An attacker can run code remotely with local system rights. Dräger medical devices do not include the Windows DNS Server, therefore they are not affected. Dräger verifies the operating system patches for software such as ICM and Infinity Gateway, and this verification continues.
