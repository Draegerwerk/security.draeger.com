### [Windows Netlogon vulnerability CVE-2020-1472 Zerologon - Dräger medical devices are not affected](<advisories/2020-09-18-PSA-20-267-01-Product-Security-Advisory-Zerologon.pdf>)

PSA-20-267-1 · 2020-09-18

Zerologon is a vulnerability in the Microsoft Windows Netlogon Remote Protocol. An attacker with network access to a domain controller can take control of all Active Directory identity services. Dräger medical devices and the related infrastructure have no Windows Server with the domain controller role. Customers can install the Microsoft patches after Dräger publishes the patch verification.
