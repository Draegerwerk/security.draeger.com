### [CVE-2022-30190 (Follina): Dräger medical products are not affected](<advisories/PSA-22-193-1-Follina-Security-Advisory.pdf>)

PSA-22-193-1 · 2022-07-13

CVE-2022-30190, called Follina, lets an attacker run code through the Microsoft Support Diagnostic Tool. Microsoft released a patch in June 2022. Dräger medical products are not affected. Dräger software-only products on Windows work with the monthly Windows update. Dräger will update the advisory if new findings occur.
