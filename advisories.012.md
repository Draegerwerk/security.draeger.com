### [URGENT/11 VxWorks network stack vulnerabilities affect some Dräger devices](<advisories/2019-07-29-URGENT11-WindRiver-VxWorks-Security-Advisory-v3.pdf>)

PSA-19-210-1 · 2019-07-29

WindRiver published eleven vulnerabilities in the network stack of the embedded operating system VxWorks, named URGENT/11. Some Dräger devices use a vulnerable VxWorks version, for example Babyleo TN500, Perseus A500 and Connectivity Converter CC300. These products need a software patch. Dräger informs the customers of affected products separately.
