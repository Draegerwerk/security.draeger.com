### [Dräger Service Connect Gateway vulnerability in versions 2.24.0 to 2.28.1](<advisories/PSA-21-347-1-SCG-Security-Advisory.pdf>)

PSA-21-350-1 · 2021-12-16

A local attacker can change a cached entry in the Service Connect Gateway and get Dräger development rights. The attacker can then install software packages signed by a Dräger developer on a medical device. Service Connect Gateway versions 2.24.0 to 2.28.1 are affected. Dräger published and installed a corrected version on 17 December 2021.
