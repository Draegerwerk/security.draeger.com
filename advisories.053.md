### [Dräger Atlan Security Vulnerabilities](<advisories/PSA-26-173-1-Product-Security-Advisory-PSA.pdf>)

PSA-26-173-1 · 2026-06-22

Penetration tests found several vulnerabilities in the Atlan anesthesia workstations A300, A300XL, A350 and A350XL with software version 1.0n. Together they can let a network attacker get full access to the device software and data, with CVSS score 8.1. Dräger fixed the problem in Atlan software version 2.11.02.
