### [Dräger Protector Software security vulnerabilities before version 6.4.2](<advisories/2021-267-01-Draeger-Protector-Software-vulnerabilities.pdf>)

PSA-21-267-1 · 2021-09-24

The file system permissions of the Protector Software let a local attacker replace program files or loaded modules. The attacker can then run code with NT SYSTEM rights. Protector Software versions before 6.4.2 are affected. Dräger corrected the software. Users must install version 6.4.2 or higher as soon as possible.
