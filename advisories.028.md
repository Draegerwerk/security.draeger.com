### [Dräger X-Dock security vulnerabilities (CVE-2021-28111, CVE-2021-28112)](<advisories/PSA-21-120-1-X-Dock-Product-Security-Advisory.pdf>)

PSA-21-120-1 · 2021-04-30

The X-Dock firmware has an unused debug port with hard-coded credentials. An attacker who gets these credentials can run code remotely on the system. X-Dock firmware versions before 03.00.13 are affected. Dräger corrected the software, and users must install version 03.00.13 or a higher version as soon as possible.
