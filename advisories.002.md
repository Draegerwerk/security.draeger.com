### [WannaCry ransomware, version 2: effect on Dräger products and necessary Windows patches](<advisories/2017-05-19-wannacry-ransomware-security-advisory-v2.pdf>)

PSA-17-139-1 · 2017-05-19

Version 2 of the WannaCry advisory adds more products, for example the old Gateway on Server 2003. WannaCry uses the Microsoft Windows SMB vulnerability MS17-010. The Infinity Acute Care System and Zeus Infinity Empowered are not exposed. For the other products, such as Infinity Explorer, Gateway, Symphony, Innovian and Infinity C700 for IT, users must install the March Windows updates.
