### [Windows RDP vulnerability CVE-2019-0708: Dräger medical devices are not affected](<advisories/2019-06-07-Windows-RDP-RCE-for-CVE-2019-0708-Security-Advisory_v4_FINAL.pdf>)

PSA-19-158-1 · 2019-06-07

Microsoft published a wormable vulnerability in Windows Remote Desktop Services. It lets a remote attacker run code with crafted packets. Dräger medical devices are not affected, because RDP is disabled and a software firewall blocks unused ports. For customer-maintained Windows systems, the advisory lists the Microsoft updates to install.
