### [Dräger Infinity CentralStation Security Vulnerabilities: Linux kernel CVEs](<advisories/PSA-26-175-1-Product-Security-Advisory-PSA.pdf>)

PSA-26-175-1 · 2026-06-24

Researchers disclosed several Linux kernel vulnerabilities: CopyFail, DirtyFrag, Fragnesia, ssh-keysign-pwn, Pack2theRoot and DirtyCBC. Infinity CentralStation software VG6.0 is affected by five of them. The versions VG4.0 and VG5.0 are not affected. To see the installed kernel, run the command rpm -q kernel --last in the console.
