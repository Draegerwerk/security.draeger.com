### [Windows RDP vulnerabilities CVE-2019-1181 and CVE-2019-1182: Dräger devices are not affected](<advisories/PSA-19-255-01-Windows-RDP-RCE-for-CVE-2019-1181-and-1182-Security-Advisory.pdf>)

PSA-19-255-1 · 2019-09-12

Microsoft published two vulnerabilities in Windows Remote Desktop Services. They let a remote attacker run code with crafted packets. Dräger medical devices are not affected, because RDP is disabled and a software firewall blocks unused ports. For customer-maintained Windows systems, the advisory lists the Microsoft updates to install.
