### [Meltdown and Spectre processor vulnerabilities: effect on Dräger products](<advisories/2018-01-04-meltdown-spectre-security-advisory.pdf>)

PSA-18-001-1 · 2018-01-04

Meltdown and Spectre let an attacker read protected memory, but the attacker must first run own code on the machine. Dräger embedded devices, such as ventilators, anesthesia devices and patient monitors, block unknown code, so the risk is very low and the patches can reduce performance too much. For products like the Infinity C700 for IT, users must test the Microsoft patch before they install it.
