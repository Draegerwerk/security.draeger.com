### [Petya, Petna, NotPetya and PetrWrap ransomware: effect on Dräger products](<advisories/2017-06-29-petna-ransomware-security-advisory.pdf>)

PSA-17-003-1 · 2017-06-29

This ransomware uses the same Microsoft Windows SMB vulnerability MS17-010 as WannaCry, but it spreads only in local networks, also with PsExec and WMIC and stolen credentials. The Infinity Acute Care System is not exposed. Users of Infinity Explorer, Gateway, Symphony, Innovian Solution Suite and Innovian Anesthesia must install the March Windows updates and can also add the read-only perfc file.
