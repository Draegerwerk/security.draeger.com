### [WIBU CodeMeter Runtime vulnerabilities in Mobile Patient Watch, X-dock Manager, Polysoft and REGARD](<advisories/2020-09-22-PSA-20-266-01-Product-Security-Advisory-WIBU.pdf>)

PSA-20-266-1 · 2020-09-22

WIBU Systems made public vulnerabilities in CodeMeter Runtime up to version 7.10. Dräger uses this component for license management. An attacker can forge a license file, stop the software, or run code (CVE-2020-14509, CVE-2020-14513). Affected installers: Mobile Patient Watch up to 1.1.1, X-dock Manager 2.0 to 3.0.2, Polysoft up to 1.10.0 and REGARD Configuration Software 01.00.00 to 01.03.00.
