### [Perseus A500 SW 2.0n security vulnerabilities](<advisories/2020-06-PSA-20-169-01-Security-Advisory-Perseus-A500-SW20n.pdf>)

PSA-20-169-1 · 2020-06-17

The Perseus A500 does not handle specially made non-Medibus data on the Medibus interface correctly (CWE-20, improper input validation). The processor becomes overloaded, the display of curves is late, and the device does a warm start. Ventilation then stops for a few seconds. Software versions 2.00 to 2.02 are affected. Check the installed version in System Setup.
