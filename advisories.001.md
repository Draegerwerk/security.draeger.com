### [WannaCry ransomware, version 1: effect on Dräger products and necessary Windows patches](<advisories/2017-05-15-wannacry-ransomware-security-advisory.pdf>)

PSA-17-135-1 · 2017-05-15

WannaCry uses a vulnerability in the Microsoft Windows SMB server, published as MS17-010, to run code and lock out users. Dräger tested all products with Windows: they are either not exposed or they stay safe with the routine operating system patches. Users of Infinity Explorer, Gateway, Symphony, Innovian, Infinity C700 for IT and SmartPilot View must install the March Windows updates.
