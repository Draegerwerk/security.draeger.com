### [Dräger Service Interface (DSI) Security Vulnerability](<advisories/PSA-26-180-1-Draeger-Service-Interface.pdf>)

PSA-26-180-1 · 2026-06-29

The Dräger Service Interface (DSI) server does not validate browser request data correctly. A specially made link can make the server start subprocesses and run any code, without authentication. All DSI versions before 1.56.3 are affected, with CVSS score 8.8. Install DSI version 1.56.3 or a later version.
