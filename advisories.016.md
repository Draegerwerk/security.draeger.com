### [SC Monitoring SC7000/SC9000 security vulnerabilities](<advisories/2019-11-27-Draeger-SC7000-SC9000-security-advisory-update-v1-5.pdf>)

PSA-19-331-1 · 2019-11-21

Dräger found two vulnerabilities in the SC Monitoring patient monitors. A malformed network packet can make the monitor reboot, and the source code holds plain-text credentials that give local access to service and clinical accounts. All versions of SC 6002XL, SC6802XL, SC 7000, SC8000 and SC90000 XL are affected. The line is End of Service, so no fix is available.
