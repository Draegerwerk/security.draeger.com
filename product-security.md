## Atlan {#atlan}

### Achieving security level 1 according to IEC TR 60601-4-5

For the Atlan anesthesia device with software 2.0x/2.1x an analysis according to IEC 60601-4-5 has been executed to identify its security level. The analysis revealed that for the security level 1 (SL-1) the following measures are required:

- If the device is used in a network, the security level of the hospital network must ensure that no attackers can access the device (isolated network).
- The operator must inform the user before accessing the device about policy requirements if needed.
- In case of logging failure, the device does not create a notification. Therefore, the device cannot achieve SL-1 in this point.

## Oxylog 2000 plus {#oxylog-2000-plus}

For the Oxylog 2000 plus ventilator device an analysis according to IEC 60601-4-5 has been executed to identify its security level. The analysis identified that certain security requirements essential for achieving Security Level 1 (SL-T = 1) need to be implemented by the responsible organization:

- Network Protection Measures: The hospital network must ensure network protection measures for isolated networks to prevent unauthorized access and potential cybersecurity threats.
- Communication Ports: The device cannot deactivate its communication ports. Therefore, do not connect any devices to the ports unless required for specific operations.
- User Policy Information: The operating organisation must inform the user about policy requirements before accessing the device, if needed, to ensure compliance with security protocols.
- Security Logging: The device does not provide a specialized security logging mechanism. Therefore, alternative monitoring measures should be considered if necessary.
- Physical Access Restriction: The device shall only be operated in an access restricted location. The operator must ensure that only authorized people have access to the device.
- Service and Maintenance: Modifications, updates, and service shall only be executed by trained service personnel.

## Babyleo TN500 {#babyleo-tn500}

For the Dräger IncuWarmer Babyleo TN500 warming therapy device an analysis according to IEC 60601-4-5 has been executed to identify its security level.

 Software Version 1.05.01 / 1.06:

The analysis revealed that security level 1 (SL-T=1) cannot be achieved. For a secure device operation in terms of IEC 60601-4-5, the following measures are required:

- The device shall only be operated in an access restricted location. The operating organization must ensure that only authorized people have access to the device.
- Do not leave the device unattended when restricted device functions are active.
- The operating organization must inform the user before accessing the device about policy requirements if needed.
- The device does not provide a specialized security logging mechanism.
- If a serial-to-network adapter is used within the devices system context, the hospital network must ensure network protection measures for isolated networks.
- Access to exported and transmitted data outside of the device must be restricted.
- Modifications, updates, and service shall only be executed by trained service personnel.
- The device is not intended for network connection, therefore the network is disabled. Do not connect the device to the hospital LAN via the Ethernet interface.
- The device contains patient-related data. In the event of disposal, remove the data by starting the device with a new patient setup in the new patient dialogue.

 Software Version 2.0.0:

The analysis revealed that for the security level 1 (SL-T=1) the following measures are required:

- The operator must inform the user before accessing the device about policy requirements if needed.
- Access to exported and transmitted data outside of the device must be restricted.
- If a serial-to-network adapter is used within the devices system context, the hospital network must ensure network protection measures for isolated networks.
