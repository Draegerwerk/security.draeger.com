### [Intensive Care Manager (ICM) Security Vulnerabilities](<advisories/Product-Security-Advisory-ICM.pdf>)

PSA-25-196-2 · 2025-08-05

The ICMHelper service of an ICM installation has a local privilege escalation vulnerability, CVE-2025-41698, which needs CVE-2025-2810. An attacker who already has access to the system can run unauthorized commands and get full access to the application, the client system and the server. ICMHelper versions 1.4.0.1 and older are affected. Install version 2.0.1.0.
